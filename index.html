Core Workflow

系统采用多阶段链式推理与多 Agent 协同结构，将数学科研材料拆解为可验证、可视化、可汇报的结构化内容。

01

文档解析 Agent

提取背景、方法、实验与创新点
02

推理规划 Agent

构建问题—理论—算法—实验逻辑链
03

数学可视化 Agent

生成技术路线图、拓扑结构图与实验图
04

内容生成 Agent

输出 PPT 文案、LaTeX、讲稿与摘要
05

校验优化 Agent

What It Solves

该项目重点解决数学科研场景中“内容难以结构化、可视化成本高、汇报制作重复劳动多”的痛点。

论文到汇报的自动转换

将论文中的研究动机、理论方法、算法流程与实验结论自动整理为适合学术答辩的 PPT 框架。

数学内容的结构化表达

针对持续同调、双参数拓扑分析等数学主题，自动提炼核心逻辑链，避免内容堆叠和表达混乱。

AI 辅助学术可视化

生成 IEEE 风格流程图、技术路线图、拓扑分析图和实验结果可视化，提升论文与汇报的专业度。

LaTeX 与 Python 工作流整合

结合 LaTeX 公式排版与 Python 实验绘图，实现数学推导、实验结果和学术表达的一体化生成。
